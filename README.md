# Abhishek S T — Unity Developer Portfolio

A responsive personal portfolio for Unity development, 2D and 3D interactive applications, and exploration of AR/VR/XR. Built with semantic HTML, CSS, and vanilla JavaScript; there is no build step or dependency installation.

## Project structure

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   └── videos/
├── projects/
│   ├── delivery-crash.html
│   ├── snow-surfer.html
│   └── smart-agriculture.html
└── README.md
```

## Preview locally

Open `index.html` in a browser. The site uses relative links and works as a static website; an optional local static-file server can also be used for previewing.

## Publish with GitHub Pages

1. Push the site files to the repository's `main` branch.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and the `/ (root)` folder, then save.
4. GitHub Pages will publish the site at `https://Abhishekst3105.github.io/`.

## Add project media

- Put optimized project screenshots and profile images in `assets/images/`.
- Put short, compressed gameplay clips in `assets/videos/`.
- Use descriptive, lowercase filenames and add real media to a project's page when available. The current project artwork is CSS-drawn and does not stand in for actual game screenshots.

## Customize

- Update portfolio content and links in `index.html` and the case studies in `projects/`.
- Adjust colors, typography, and breakpoints in `css/style.css`.
- Keep interactive behavior dependency-free in `js/script.js`.
