Smart Agriculture Monitoring

A sensor-based monitoring system designed to make environmental data more useful for agricultural decisions.

IOT · ACADEMIC PROJECT 03

About the project

This academic project used an Arduino UNO and ESP8266 Wi-Fi module to monitor environmental conditions in real time. It collected soil moisture and temperature data to support automation decisions.

What I worked on

I helped develop the monitoring system and checked sensor readings and data transmission over repeated test cycles. The goal was to reduce manual monitoring effort through data-driven automation.

Components & concepts

  • Arduino UNO
  • ESP8266
  • Soil moisture
  • Temperature
  • Wi-Fi
