Snow Surfer 2D Game

A physics-based snow surfing game that pairs downhill movement with flips, power-ups, and character choices.

UNITY · 2D GAME ✦ 02

About the project

I developed a 2D snow surfing game using Unity and C#. I explored how physics-based movement and level surfaces can shape the feel of a small arcade game.

What I built

Player rotation, movement, and speed control use Rigidbody2D and Surface Effector 2D. The game also includes crash detection, particle effects, level restart, flip-based scoring, power-ups, and a character selection UI.
