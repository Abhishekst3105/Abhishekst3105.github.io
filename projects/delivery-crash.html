Delivery Crash Game

A 2D delivery driving game built around steering, speed, and bouncing back from a crash.

UNITY · 2D GAME ↗ 01

About the project

I developed a 2D delivery driving game using Unity and C#. The project gave me hands-on practice building responsive vehicle controls and connecting gameplay events to clear player feedback.

What I built

Player steering and vehicle movement use Unity’s Input System. Pickup objects and collision detection power a speed boost, while crash detection triggers an automatic level restart through Unity Scene Management.

  • C#
  • Input System
  • Collision detection
